## Source method

The presentation defines a five-step practice:

1. **Write all thoughts about a problem.** Do not edit or filter; keep writing until nothing remains in mind.
2. **Organize the writing.** Questions become next steps or investigations; solution ideas get follow-up; reactions and feelings become questions.
3. **Identify islands of subproblems.** Each island contains nodes, interconnections, and a smaller problem to solve.
4. **Let the mind reach a diffused state.** Stop, zoom out, and create space for distant connections before resuming.
5. **Repeat and socialize.** Revisit the cycle as new problems and solutions appear; discuss the work with others to accelerate learning.

The source expects the evolving analysis to graduate into a specification, architecture, or other concrete problem-solving artifact.

## Agent adaptation

The package preserves the source loop and adds operational safeguards needed by an agent:

- a raw-capture ledger so compression is visible;
- item types and required transformations so reactions are not dropped;
- explicit island nodes and edges;
- a synthetic diffuse pass for urgent work where a real break is impossible;
- Quick / Standard / Deep modes with bounded one-cycle, two-cycle, and human-gated recursion;
- a stable-placeholder privacy gate before raw capture;
- convergence and stop conditions;
- cross-runtime installation notes;
- public-safety and validation checks that reject the source PDF and unexpected package file types.

These additions package the author's method for reliable agent execution. They do not claim that the original presentation specified agent runtimes, evaluation, or package validation.
