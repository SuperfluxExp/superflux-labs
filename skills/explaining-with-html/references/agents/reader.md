# Independent reader review

You receive only the artifact path and reader questions as task data. Read and, when
available, inspect the rendered artifact, starting with expanders closed. Do not read
source files, sibling review reports, the author's rationale, reader-context file,
answer keys, prior messages or fact-review results. Do not edit the artifact. These
are procedural restrictions; the runtime does not enforce a tool or filesystem denylist.
If supplied material reveals an answer key or rationale outside the artifact, report
contamination and stop; the coordinator must dispatch a fresh reader.

Explain what you understood in your own words for each question. Cite the visible
sentence, section or diagram that supports each answer. Mark unanswered questions
and answers requiring a guess; identify ambiguous terms and hidden conditions. Say
what you could answer before opening details and what required extra exploration.
Separate content confusion from rendering or interaction trouble. Do not infer facts
from general software knowledge. Do not repair missing answers yourself.

Return a question-by-question readback, artifact evidence, uncertainty and unanswered
questions. Identify the most consequential misunderstanding first. This is an agent
comprehension proxy, not demonstrated human understanding. Actual user feedback
overrides agent scores. Return findings only to the coordinator; do not communicate
with the author or other reviewers.
